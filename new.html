Dungeonpunk 2 Update: Combat 2.0 Is Live (And It’s Big)

Big update today. We’ve been rolling out a major Combat 2.0 upgrade, and this release brings a lot of meaningful changes to progression, loot, and character reliability.

Combat 2.0 Highlights

Combat and gear depth have expanded significantly:

  • 18-tier material progression from early-game basics to true endgame materials
  • Expanded weapon ecosystem across classic and new families
  • Armor now supports six full families with clearer identity and build impact
  • Better support for class-native combat, including amplifier-style gear that boosts your core kit instead of replacing it

This is a major step toward making build choice matter more moment-to-moment, not just at endgame.

Loot Generation Improvements

Loot variety is now much more consistent with the expanded gear system:

  • Weapon family rolls now properly include the expanded family pool
  • Biome/source weighting still shapes identity, but no longer collapses into legacy-only outcomes in generic paths
  • Better alignment between content tables and actual drop behavior in live play

In short: more of the new gear actually shows up where it should.

Server-Authoritative Item State

We’ve begun the move to stronger server authority for item mutations and character-linked item state:

  • Server-backed item state per character
  • Revision-aware mutation flow to reduce desync/conflict issues
  • Improved persistence and resync behavior for inventory/equipment changes
  • Cleaner long-term foundation for multiplayer-safe and anti-desync systems

This is foundational work that makes future features safer to build.

Character Slot & Switching Fixes

We also fixed some painful account/character flow issues:

  • New characters now appear immediately in character lists
  • Switching away from a newly created character no longer “loses” it
  • Character deletion now works reliably even when a character exists in save entries but not yet in character-state records

Result: character management is now much more dependable.

Content & Catalog Work

On the content side, we’ve continued organizing and polishing equipment data:

  • Full refreshed equipment catalog work completed
  • Weapon entries now also available in tier-first organization for easier balancing/review workflows

What This Means for Players

This patch makes the game feel more complete in three important ways:

  1. More gear identity and build expression
  2. More reliable progression and character management
  3. A stronger technical base for upcoming Combat 2.0 features

More is coming, but this is a major milestone. If you’ve been waiting for a good time to jump back in, this is one of them.
